Existing_Integration регистрирует информацию и health в общем реестре, добавляет
в мастер страницы только при фактически зарегистрированных блоках/шорткодах.
Он не устанавливает эти плагины, не меняет их настройки и не копирует платёжную логику.
При отсутствии Core самостоятельные функции исходных плагинов не затрагиваются.

## Внешние сервисы

Три независимых ZIP: Telegram, WhatsApp, Facebook-публикации. Общая кодовая база
extensions/common включается в каждый пакет, а общий Lock собирается из Core исходника
с самостоятельным namespace. Это не обязательная runtime-зависимость от Core.
Все подключения выключены до заполнения и явного подтверждения настроек.

Публикации выбираются на каждой записи WordPress; нет рассылки всех исторических
Posts. Уведомления Core включаются отдельно. Личные данные обращений не отправляются.
Очередь: opt-in → уникальный fingerprint текста/получателя → WP-Cron → фиксированный
HTTPS API URL → проверка JSON/HTTP ответа → sent/failed. Временные ошибки повторяются
ограниченно. Ошибка не раскрывает token или текст исключения; успешный API ответ
означает принятие сервисом, не доставку человеку. После исправления настроек есть
отдельный явный retry. При смене получателя прежняя задача не отправляется новому.

Объекты запросов и queued notification metadata удаляются через privacy событие.
Tokens сохраняются в WordPress options без autoload, не включаются в исходники/Git.
В job payload tokens отсутствуют. Обычное удаление расширений сохраняет настройки.
При неопределённом сетевом сбое после принятия запроса API повтор может создать
дубликат на стороне сервиса: без provider idempotency нельзя обещать exactly-once.

Официальные интерфейсы: Telegram Bot API sendMessage; WhatsApp Cloud API шаблон с
одним текстовым body-параметром; Facebook Graph API /Page-ID/feed. Версия Graph API
задаётся владельцем из настроек его приложения. Входящие webhooks/OAuth wizard не
реализованы: используются предоставленные владельцем существующие tokens/шаблоны.

Документация: https://core.telegram.org/bots/api#sendmessage,
https://developers.facebook.com/docs/whatsapp/cloud-api/,
https://whatsapp.github.io/WhatsApp-Nodejs-SDK/api-reference/messages/template/,
https://developers.facebook.com/docs/pages-api/posts/.

Существующие исходники сверены, но их runtime mounting первоначально отклонён
автоматической проверкой безопасности. Для этой проверки запрошено разрешение.
Живые аккаунты/платежи/доставка email/API не проверены и не выдаются за проверенные.
