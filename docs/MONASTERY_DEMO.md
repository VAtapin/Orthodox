# Наполненные демо-страницы

На prihod.georg-kloster.ru опубликованы 13 страниц, назначена главная (ID 7),
создано меню с группами «Обитель», «Паломнику», «Читать», «Помочь и обратиться».
Тексты адаптированы по публичным материалам сайта владельца georg-kloster.ru.
Шесть публикаций имеют исходные даты, изображения и ссылки на полные материалы.
Восемь файлов импортированы в медиатеку; галерея содержит пять фотографий.
Профиль, место служения и духовенство заполнены публичными сведениями монастыря.

Пять разовых литургий взяты из датированного расписания на октябрь 2026 года:
17, 18 и 24 октября в 12:00; 25 и 31 октября в 13:00, Europe/Berlin.
Старый общий текст «суббота/воскресенье 10:00» не превращён в регулярное правило.
Перед поездкой посетителю предложено сверять актуальное расписание оригинала.

Материалы остаются обычными редактируемыми блоками WordPress. Страницы календаря,
расписания и фотографий используют широкий шаблон. Формы подключены к настоящим
провайдерам. Реальные платежи, отправки писем и публикации в соцсетях не тестировались.
UI поддерживает четыре языка; эти редакционные материалы подготовлены по-русски.

Исходный набор: scripts/monastery-content.json; явный импорт:
scripts/apply-monastery-demo.php. Эти файлы не входят в универсальный ZIP темы.
Импорт ограничен указанным доменом и администратором. Ручные изменения и корзина
сохраняются; фотографии, статьи и службы повторно не создаются. Профиль и фотографии
темы заполняются только в незаполненных полях. Группировка заменяет только исходную
неизменённую демо-навигацию. Это отдельное наполнение по запросу владельца.

Пять схем доступны в «Приход → Настройки → Оформление прихода». «Посмотреть сайт»
под каждой схемой открывает её предварительный вид главной, доступный владельцу;
сохранённые настройки и оформление посетителей при этом не меняются. Для всего
сайта выберите схему и сохраните её в этой же панели.

Снимки всех страниц и схем находятся в docs/test-server/monastery-*.png;
проверки размеров — monastery-pages-qa.json и monastery-mobile-qa.json.
Дополнительно сохранены service-editor-redesigned.png и admin-navigation-facebook.png.

Обновление файлов выполняется командой в docs/TEST_SERVER.md. Повторное наполнение
уже подготовленным набором, только внутри этого WordPress:

```bash
cd /var/www/vhosts/prihod.georg-kloster.ru/httpdocs && \
export PATH="/opt/plesk/php/8.5/bin:$PATH" && \
php -d memory_limit=512M /usr/local/bin/wp eval-file wp-content/prihod-packages/apply-monastery-demo.php --user=prihod-owner
```

Повторная сверка по всем макетам — DESIGN_CONFORMITY.md, новые снимки —
design-reference/verification-2026-10-12/. История использует шаблон about только
для неизменённого демо; исходный текст и ручная редактура сохраняются.
