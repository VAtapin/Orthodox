# Календарные подсказки — Core 1.0.0-rc.10

Готово локально, на сервер не установлено. Сторонний orthocal не изменён.
Тема 0.3.18 остаётся отдельным обновлением с ожидающим разрешением.

## Редактор службы

При выборе даты асинхронно запрашивается существующий
`Orthocal_Plugin::request('calendar', 'day', ...)`. Используются подключение,
профиль, локализация, кеш и обработка ошибок провайдера. Нет собственных
таблиц праздников, API ключей или копии календарного алгоритма.
Пасха, двунадесятые и великие праздники — реальные `commemoration/typeCode0..2`.

Кнопка предлагает «Литургия · название праздника». Только явное принятие заполняет
пустое название; ручное название не заменяется. Время и место не назначаются.
Ссылка из напоминания подставляет дату и оставляет время пустым. Регулярная служба
сохраняет тип повторения. Смена даты отменяет старый запрос и убирает старую подсказку.
Ошибка API не мешает ручному заполнению. REST требует права управления расписанием
и штатный WordPress nonce. На сервере нет блокировки настроек/HTTP/почты.

## Икона дня

Одна галочка в редакторе. Старые службы по умолчанию без иконы. Для каждого
реального вхождения используется его локальная дата, включая переносы. Изображение
берётся первым в авторитетном порядке `Orthocal_Plugin::icon_items`, его загрузка —
через существующий подписанный медиасервис и кеш orthocal. Ручного выбора/загрузки
икон и подмены изображением другого дня нет.

Публичный HTML расписания не ждёт API: изображение загружается асинхронно;
повторные карточки одной даты используют один запрос. Публичный endpoint разрешён
только для опубликованных, неотменённых вхождений с включённой галочкой и использует
существующий throttle провайдера. Нет изображения/ошибка — карточка остаётся без
пустой рамки; редактор показывает «Икона дня недоступна». Логотипы не затронуты.
Компактные карточки главной темы не менялись этим блоком.

Мобильный месяц сохраняет сетку всех дней с количеством служб. Выбранный день
раскрывается ниже на полной ширине, включая дату, время, название, место и икону.
Выбор доступен клавиатурой, обновляет поле даты и URL; пустой день имеет явное
сообщение. Без JavaScript остаются нативные раскрывающиеся сведения каждого дня.
Desktop сохраняет прежние полные карточки внутри месяца. При печати выводится
полная таблица; сведения не удаляются из расписания.

## Напоминание

Раздел «Приход → Настройки → Общие настройки» содержит день недели, время и
включение. По умолчанию выключено, время не назначено. Получатель — `admin_email`
этого WordPress; timezone — сохранённый пояс прихода. Владелец ещё не выбрал время.
WordPress Cron зависит от посещений сайта; новый серверный cron не устанавливается.

Одиночные события рассчитываются по местному времени на каждую неделю с учётом DST.
Несуществующее время при весеннем переводе пропускается, осенью выбирается первое
вхождение. Изменение настроек/пояса/модуля перепланирует только собственное событие.
Деактивация прекращает его; обычное удаление сохраняет настройки, явное удаление
данных «Прихода» очищает их вместе с собственным Cron.

Письмо перечисляет праздники ближайших семи дней и ссылки в защищённый редактор;
службы не создаются и не публикуются автоматически. При задержке Cron прошедшие
праздники исключаются. Блокировка только конкурентного запуска собственного задания
и запись попытки предотвращают повтор письма; отказ почты не приводит к автоповтору.
Ошибка календаря даёт максимум две повторные попытки через час; успех `wp_mail`
означает принятие почтовой службой, не доказанную доставку.

## Названия праздников и цвета — Core rc.11 / тема0.3.21

Праздник выводится рядом с фактической службой на пяти главных и в обзоре,
неделе, месяце (включая мобильную карточку дня) и списке. Повтор полного названия
в ручном заголовке подавляется. Публичный REST отдаёт только праздники дат
опубликованных неотменённых служб; редакторский endpoint по-прежнему требует права.
Нет связи с календарём — служба и выбранный цвет остаются доступны.

Палитра: белый, красный, золотой/жёлтый, зелёный, голубой, фиолетовый, чёрный,
плюс «Без выделения». Образцы сопровождаются подписями; публичный цвет — мягкий
боковой акцент и текстовая подпись. Исключение «Цвет облачения на эту дату» сохраняет
время/место и остальные повторения, не появляется в списке переносов. Перенос может
иметь собственный цвет; рекомендация относится к новой местной дате.

Рекомендация не заявлена как поле календарного API: это ограниченное соответствие
названия праздника традиции (Богородичные — голубой, Троица/Пятидесятница — зелёный,
Преображение — белый). При неизвестном или конфликтующем наборе предлагается ручной
выбор. Основание: [описание символики облачений ROCA](https://roca.org/oa/volume-iv/issue-32/the-symbolism-of-vestments/).
Остальные цвета выбираются вручную. Новый незаполненный цвет одиночной службы/даты
может принять рекомендацию; сохранённый и ручной выбор, включая нейтральный,
не перезаписывается. Есть явная кнопка принятия рекомендации. Для регулярной серии
рекомендация праздника применяется через исключение, а не ко всем неделям.
Смена даты отменяет запрос и игнорирует устаревший ответ.

## Core rc.13: автоматический режим и компактный вывод

Выбор «Автоматически по календарю» хранится как auto. Каждая фактическая дата
(после переноса) получает рекомендацию при чтении календаря; вычисленный цвет
не сохраняется в правило серии. Явный ручной цвет или нейтральное исключение
приоритетны. Выбирается высший явно заданный ранг 0–5; обычные памяти не
переопределяют великий праздник. Распознанный мученик — красный, преподобный —
зелёный, святитель/апостол — золотой. Неизвестное/смешанное событие — без догадки.
Полный алгоритм великопостных периодов, воскресных совпадений и всех попразднств
ещё не реализован. Основание: https://azbyka.ru/shemy/cveta-bogosluzhebnyh-oblachenij.shtml

Текстовый badge цвета на публике удалён. Карточка изменений выводится только
при реальных отменах/переносах и не оставляет пустую колонку. Икона включена
также в ближайшую службу. Клиент объединяет праздник/цвет/икону в один запрос
на дату; используется существующий cache orthocal с разрешённым API TTL ≤300s,
без изменения внешнего плагина или серверных настроек.

При чтении живого WordPress12октября источник вернул icons=[] на24/25октября.
Предпросмотр редактора относится к началу серии, а не ко всем её повторениям.
Икона другой даты не подставляется. Собственные временные диагностики удалены.
Локально проверены загрузившиеся реальные иконы; пять главных1280px без наложений
после загрузки длинного Покрова, без надписи цвета. Снимки *-rc13 и metrics JSON.
