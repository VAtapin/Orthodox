# Мастер

Ответы хранятся в user meta отдельно для каждого пользователя и сайта. Они не
изменяют профиль или страницы до подтверждения плана. Состояние имеет revision;
устаревшая вкладка не сохраняется. Пользователь может пропустить вопросы или
перезапустить интервью без удаления ресурсов.

Анализ учитывает тему, страницы и навигации, главную, меню/позиции, язык, timezone,
активные плагины, профиль, модули и реестр ресурсов. Snapshot fingerprint
перепроверяется непосредственно при применении. Реестр ресурсов хранит IDs и
признак владения; теги страниц позволяют восстановиться после неполного выполнения.

Создание мест, духовенства, первой службы и страниц — только черновики.
Существующие страницы используются без переписывания. Категории создаются только
по выбору. Подробное расписание настраивается через готовый модуль.

Публикация, назначение главной и выбор позиции классического меню — отдельное
подтверждение. Изменённый вручную черновик публикуется индивидуально в редакторе.
Блоковая навигация создаётся отдельным ресурсом; шаблоны темы не переписываются.
Созданная ранее навигация/меню сохраняются при повторном запуске; отдельно выбранные
новые страницы добавляются без удаления прежних пунктов и повторения существующих IDs.
Тема/расширения не устанавливаются скрыто.

Диагностика не выдаёт конфигурацию почты за доказанную доставку. GET prihod/v1/status
требует manage_prihod_settings и не возвращает обращения/credentials.

Очистка: отдельная страница, nonce, права и буквальное УДАЛИТЬ. Данные очищаются
пакетами по 100 через WP-Cron, новые обращения на это время блокируются. Существующие
страницы, использованные мастером, сохраняются. Созданные им страницы/навигация/меню
удаляются только при отдельном выборе, включая ручные изменения. Нужна резервная копия.

В RC.2 приветствие предшествует интервью. Шесть групп в левой колонке объединяют
14 существующих подробных этапов; права, блокировки, ревизии и отдельные подтверждения
применения/публикации сохранены. Основной язык выбирается из русского, немецкого,
польского и украинского. Этот выбор описывает приход и не переключает язык WordPress.
Пять схем доступны в редакторе установленной темы «Приход». Мастер не устанавливает
тему и не активирует внешние плагины. Экран окончания сообщает о подготовленных
черновиках; публикация остаётся самостоятельным действием.
