# Мастер и собственные экраны — Core rc.9

12 октября 2026 года с прямого разрешения владельца установлены Core rc.9 /
тема 0.3.17 в prihod.georg-kloster.ru. 67 серверных проверок прошли на PHP8.5.11.

Мастер содержит шесть настоящих этапов: приветствие, сведения, возможности,
страницы, подтверждение, результат. Контакты, четыре языка и часовой пояс
сохранены внутри сведений; подробности выбранной функции раскрываются внутри
общего списка. Подготовка духовенства и мест не удаляет существующие записи.
Отключённые функции не требуют заполнения своих полей.

Сохранённое прежнее интервью сопоставляется новому этапу без удаления ответов
и ресурсов. Старые открытые формы требуют обновления вкладки. Назад и
«Настроить позже» сохраняют ответы; неверный часовой пояс остаётся в поле
для исправления. До подтверждения страницы, меню, профиль и тема не меняются.
Уже установленная тема и одна из пяти схем применяются только по подтверждённому
выбору. Установки новых компонентов нет. Публикация и назначение меню/главной
сохраняют отдельное подтверждение и проверку ручных изменений.

Общий фон, белые панели, поля, кнопки, фокус и верхнее меню ограничены собственными
экранами Core/темы/подключений. На телефоне меню имеет две колонки. Сторонние
календарь и пожертвования сохраняют своё оформление. Обычная консоль WordPress
получает оформление только четырёх собственных виджетов. После завершения мастера
приглашение начать настройку больше не показывается.

## Проверки

- PHP syntax и 57 изолированных unit assertions.
- 2034 переводных UI сообщений/placeholder; собраны только каталоги Core.
- Playground CLI 3.1.57: WP 7.1.3 / PHP 8.4.25 — 253 assertions;
  WP 6.5.13 / PHP 8.0.30 — 242; оба процесса завершились с exit 0.
- 191 проверка структуры темы и повторный импорт с сохранением ручных правок.
- Реальные переходы всех шести этапов, подтверждение только в одноразовой базе,
  обратный проход до приветствия, ошибка/исправление часового пояса и фокус.
- 23 экрана на 1122×900 и 390×844: обзор, информация, профиль, плагины, настройки,
  модули, подключения, Facebook, Telegram, WhatsApp, диагностика, права, данные,
  панель темы, обращения и локальный пример карточки, три списка, три редактора,
  консоль WordPress. Общее меню присутствует на всех собственных экранах.

Размеры и снимки — `design-reference/verification-2026-10-12/`:
`admin-rc9-metrics.json`, `wizard-rc9-metrics.json`, `theme-panels-rc9-metrics.json`.
У 46 проверенных состояний нет горизонтального переполнения документа. Отдельно
измерены заголовок, редактор и обе колонки метабоксов на телефоне: их границы
помещаются в доступную ширину. Все семь разделов темы переключаются; после
загрузки скрипта виден только выбранный раздел. Высота зависит от его содержимого.

Старый захват fullPage до загрузки скрипта давал неверные длинные изображения.
Итоговые `local-admin-*` / `mobile-admin-*` — обычные снимки после события load;
они показывают видимую область, а не всё содержимое длинной формы.
WordPress в локальном runtime английский, собственный интерфейс русский.
Внешние плагины в GUI действительно активны; запись обращения синтетическая,
не создавалась через форму отправки. Реальные письма, оплаты и публикации не
отправлялись. Серверная проверка rc.9 прошла. Снимки живого сайта дополняют локальные.

## Ограничения приёмки

Сравнение с макетом качественное, не измерение 99% пиксельного совпадения.
Настоящие тексты, дополнительные настройки и число уже существующих страниц
изменяют высоту карточек. Локальные снимки дополнены 46 состояниями живой админки
и65состояниями опубликованных страниц пяти оформлений; границы — DESIGN_CONFORMITY.md.
Всплывающий просмотр фотографий и белые поля портретных карточек — следующий
отдельный блок темы. В этой задаче файлы темы и сторонних плагинов не изменялись.
