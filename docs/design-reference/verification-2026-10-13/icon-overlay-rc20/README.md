# Проверка икон расписания — Core rc.20

Локальный WordPress Playground, тема 0.3.28. Снимки после загрузки икон:
пять оформлений × неделя/месяц/список × 1440/390 px = 30 случаев.
`metrics.json` фиксирует загрузку изображений, совпадение прозрачной кнопки
штатного просмотра с иконой, доступную подпись, фокусируемость и отсутствие
горизонтального переполнения. `tests/icon-overlay20-check.py` проверяет эти
измерения и размеры снимков. `viewer-mouse.jpg` и `viewer-keyboard.jpg`
подтверждают открытие образа Спасителя мышью и клавишей Enter. На 390 px
кнопка имеет ширину не менее 44 px; при фокусе икона получает видимый контур.

Это локальная проверка до установки Core rc.20 на production.
