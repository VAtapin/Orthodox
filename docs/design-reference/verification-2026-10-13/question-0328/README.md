# Общая форма и фотография — тема 0.3.28

Локальная проверка пяти оформлений: classic, hospitality, editorial, tradition,
blue; ширины 1920, 1440 и 390 px. JPEG сняты после загрузки фотографии.
metrics.json содержит измерения настоящей страницы, проверяемые
`tests/question-layout28-check.py`.

Фотография находится внутри общего контейнера заголовка, на телефоне — под
заголовком. Форма имеет одинаковые отступы: 24 px на компьютере, 16 px на
телефоне. Поля заполняют внутреннюю ширину панели; горизонтального переполнения
и наложения фото на заголовок нет. Используется существующее выбранное фото.

Форма не отправлялась. Эти снимки подтверждают локальную вёрстку, а не установку
версии на production. Core rc.18 с общей поправкой мини-календаря подготовлен
отдельно; установка обеих версий требует прямого разрешения владельца.
