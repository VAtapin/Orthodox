# Приёмка запасных икон Core rc.14

Снимки без префикса live — локальный WordPress 7.1.3 с темой 0.3.22.
Пять настольных схем при 1280px: classic, hospitality, editorial, tradition, blue.
В каждой после загрузки проверены семь изображений (натуральная ширина >0)
и отсутствие горизонтального переполнения. Подписи в месячных ячейках содержат
часовой пояс без повторной полной даты. Включённые примеры 17/18/24/28 октября
имеют автоматически полученный золотой цвет; 14/21 — ручные синий/красный.
Существующие локальные примеры 25/31 с выключенной иконой/цветом сохранены.

На 390px открытая карточка 18 октября содержит настоящее местное изображение
Воскресения Христова (naturalWidth330), золотую линию и полные сведения;
горизонтального переполнения нет. Полная дата мобильной карточки сохранена.
В медиатеке выбран существующий локальный тестовый attachment, настройка
сохранена и перечитана; затем восстановлен встроенный образ и сохранён снова.
Снимок settings показывает оба встроенных образа после восстановления.

Первые кадры делались до завершения календарных запросов; полные снимки
calendar-fallback-{scheme}-rc14 отражают окончательную загрузку.
Синтетические изменения сделаны только в собственной одноразовой локальной базе.

Снимки live-calendar-* сделаны после разрешённой установки Core rc.14
в prihod.georg-kloster.ru.85серверных проверок прошли;1280px — все10служб
с цветом и загруженной иконой,4из календаря/6запасных, без повторной даты;

Живые служебные параметры не редактировались. Их отпечаток и отпечатки
профиля/темы/Telegram/модулей совпали до и после. Письма/сообщения не отправлены.
