# Образец письма с приватным изображением — rc.16

mail-1440.png и mail-390.png сняты в браузере с локального HTML настоящего
Request_Mail::render. Данные вымышленные; синее изображение — тестовый PNG,
не файл посетителя. MIME-тест отдельно проверяет Content-ID/embedded bytes и
multipart/alternative до перехваченной отправки; здесь CID заменён на data URI
только для визуального локального образца. Обе ширины без overflow.
Реальная доставка почты не проверялась, Gmail и внешние отправки не использовались.
