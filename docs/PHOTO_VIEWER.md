# Просмотр фотографий — тема 0.3.18

Подготовлено локально. На prihod.georg-kloster.ru пока установлена 0.3.17;
разрешение на Core rc.9/0.3.17 не распространяется на установку 0.3.18.

Используется штатный просмотрщик Image WordPress. Тема включает его по умолчанию
для Image/Gallery и выводит собственные фотографии через тот же блок. Главная,
обитель, духовенство, паломнику, контакты, каталоги, статья и связанные материалы
сохраняют прежние источники, подписи и ссылки. Изображение карточки ведёт по своей
ссылке; отдельная штатная кнопка увеличивает его. На телефоне кнопка видима и имеет
размер44px. Логотип, символы и фоновые фото не становятся галереями.

На WP7 штатный Gallery регистрирует порядок динамических фотографий темы.
На WP6.5–6.9 тема добавляет две кнопки и клавиши к существующему просмотрщику,
переключая его штатными кнопками исходных Image. Второго модального окна нет.
Подписи/номер, полный кадр через contain, безопасные отступы, Tab и возврат фокуса
дополняют нативное окно. Настройки уже авторских Image (явное отключение просмотра
или собственная ссылка) сохраняют штатное поведение WordPress. Контент/настройки
сайта не переписываются; сторонние плагины не изменены.

Основание: [настройки Image lightbox](https://developer.wordpress.org/themes/global-settings-and-styles/settings/lightbox/)
и реальный код Image/Gallery из официальных WP7.1.3 и6.5.13 в Playground.

## Проверки

- Официальный Playground: WP7.1.3/PHP8.4.25 —242 assertions и204 проверки дизайна;
  WP6.5.13/PHP8.0.30 —242 и203 соответственно. Самостоятельная тема и повторный
  импорт с сохранением ручных правок проходят в обоих прогонах.
- PHP syntax, Node syntax для photos.js,2040 проверок переводов/placeholder.
  Новые строки RU/DE/PL/UK; каталоги Core не изменены.
- Галерея: пять схем×1122/390px в обеих версиях WP. Next/Previous, стрелки,
  Escape/Close, Tab, подпись, полный кадр, прокрутка и исходный фокус.
- WP7: восемь типов страниц×пять схем×1122/390px —80 состояний с реальным
  открытием фотографии. Desktop — кнопкой мыши, mobile — мышью/Enter; на mobile
  видима штатная кнопка44px. Вложенных кнопок в ссылках и overflow нет.
- Десять галерей главной: переход с первой на последнюю фотографию, включая
  полную blue-подборку и фото за пределами полосы tradition. Ссылка статьи и
  preview сохранены. Ошибок JavaScript в двух локальных браузерных прогонах нет.
- Последняя правка сохраняет штатные фильтры миниатюр WordPress; после неё
  фотографии новостей главной и связанных статей повторно открыты во всех пяти
  схемах на1122/390px —20 дополнительных состояний без overflow.

Снимки/метрики: docs/design-reference/verification-2026-10-12/*0318*.
Фактический viewport записан в JSON. Ошибочно снятые desktop вместо mobile
состояния заменены; их нельзя считать отдельной мобильной проверкой.

Внешние календарь/пожертвования не активируются в прогоне PHP8.0: их современная
версия имеет собственные требования PHP. Проверка минимума относится к Core/теме.
Замедленная загрузка/ошибка изображения не имитировались отдельным сетевым тестом.
Общий процент99% соответствия исходным макетам не измерен. Просмотр вошёл в
разрешённую и установленную0.3.19 вместе с исправлением портретных полей.
Страница19 проверена на сайте во всех пяти схемах на1122/390px: открытие,
перелистывание/подпись/целый кадр и закрытие.72 серверные проверки прошли;
