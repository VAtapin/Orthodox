A parish theme with five visual styles for standard WordPress pages and posts.

== Description ==

Georg-Kloster Prihod provides five visual styles: Classic, Hospitality, Editorial, Tradition, and Blue. The theme works on a standard WordPress installation without a companion plugin. Choose a style and your own images under Appearance > Parish Appearance. Standard pages and posts remain editable in WordPress.

The theme does not create pages or send data to external services. Optional parish plugins can provide contact, calendar, and schedule content. The theme only displays content available on the site. No bundled photographs appear on the public site.

== Installation ==

Upload the theme ZIP under Appearance > Themes, activate it, then choose a visual style under Appearance > Parish Appearance. Add your own pages, navigation, logo, and photographs in WordPress. An optional OpenStreetMap iframe loads only when its HTTPS embed URL is saved in the theme settings. This sends the visitor's browser request to OpenStreetMap; see https://osmfoundation.org/wiki/Privacy_Policy. No other remote service is contacted by the theme.

== Frequently Asked Questions ==

= Does the theme require a plugin? =

No. It displays ordinary WordPress pages and posts on its own.

= Where do the photographs come from? =

The theme uses images selected from your WordPress media library. It does not download or import photographs.
