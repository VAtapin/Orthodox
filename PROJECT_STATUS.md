# Статус «Прихода»

Реализованы этапы 1–6: Core, расписание, обращения, мастер, права/диагностика/
очистка и самостоятельные тема/подключения. Core 1.0.0-rc.3, тема 0.3.1,
Telegram/WhatsApp/Facebook 0.1.1. Сборка ZIP — python scripts/package.py.
Это release candidate. ТЗ и исходные макеты сохранены.

Тема: пять схем, четыре шаблона внутренних страниц, панель управления с семью
разделами, ширина/шрифты/фото/логотип/шапка/подвал/формы/языки/демо. Сохранённые
стили WordPress имеют приоритет. Предпросмотр пяти схем главной доступен владельцу
без записи настроек. Русский, немецкий, польский и украинский UI; редакционные
материалы не переводятся автоматически. Исправлены размеры карточек и перекрытие
приветствия в классической схеме; светлая схема размещает карточки в три колонки.

Core: «Обзор прихода» вместо «Дашборда», тематические разделы меню и общая верхняя
навигация внутренних страниц, подключений и редакторов. Кнопка мастера, настоящие
состояния/версии наших плагинов, четыре виджета консоли. Форма богослужения имеет
основные поля в сетке, повторение, раскрываемые описание/часовой пояс/переносы.
Редактор WordPress и правила расписания сохранены. Права доступа не расширены.

Мастер создаёт стандартные блоки и реальные формы провайдеров. Демо по умолчанию
черновые; повтор сохраняет ручные правки и корзину. По прямому запросу владельца
на prihod.georg-kloster.ru опубликованы и полностью наполнены 13 демо-страниц,
назначена главная ID 7 и сгруппировано меню. По georg-kloster.ru подготовлены шесть
материалов с исходными датами и ссылками, восемь изображений, профиль, место служения,
духовенство и пять разовых октябрьских литургий. Собственная ручная редактура сохраняется.
Набор монастыря — отдельный явный импорт, не часть универсальных ZIP; MONASTERY_DEMO.md.
Календарь/расписание/галерея имеют широкие шаблоны; календарь не дублируется в боковой колонке.

Установлены WordPress 7.1.3, актуальные Core/тема, orthocal 1.3.78,
Orthodox Donations 1.0.2 и три подключения. Календарь получает реальные данные
публичного API без ключа; поддержаны актуальные gkod_* и прежние kloster_* формы.
Платёжная логика остаётся во внешнем плагине. Реальные оплаты, доставка писем и
внешние публикации не проверялись; настройка внешних аккаунтов требует данных владельца.

Сайт находится на ОБЩЕМ БОЕВОМ сервере с другими живыми сайтами. Все действия
ограничены этим WordPress. Plesk/окружение и другие сайты не изменялись;
HTTP/email не блокируются, новых блокировок нет. Пароль администратора изменён
владельцем; первоначальный файл устарел. Credentials не входят в Git.
Фактический PHP сайта 8.5.11, MariaDB 10.6.23; команды — docs/TEST_SERVER.md.

Проверки: PHP syntax, 57 unit assertions, JavaScript syntax, 1491 переводное
UI-сообщение и placeholders. WordPress Playground: 168 assertions на WP 7.1.3 /
PHP 8.4.25 с настоящими календарём и выпущенным пожертвованием 1.0.2;
157 на WP 6.5.13 / PHP 8.0.30. Отдельно прошли standalone и полный импорт
13 страниц / 6 материалов / 8 медиа с повтором и сохранением ручной правки.
На сервере — 35 проверок, подтверждены версия Core, 13 публикаций и главная ID 7.
Браузер: все страницы, пять схем, редактор службы/верхнее меню и мобильные формы;
изображения загружаются, горизонтального переполнения нет. Снимки — docs/test-server/.
CI настроен, удалённый результат не заявляется пройденным. Следующее — редактура
демо владельцем и отдельная проверка реальных платёжных/социальных подключений.
