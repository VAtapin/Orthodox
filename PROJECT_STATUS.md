# Статус «Прихода»

Готовы этапы 1–5: Core, полное расписание, обращения, безопасный мастер,
административные права/диагностика/очистка и необязательная блоковая тема «Приход».
Плагин 0.5.0, тема 0.1.0. Тема содержит шаблоны страниц/записей/главной,
header/footer, patterns прихода и светлый/вечерний варианты. Данных и бизнес-логики
в теме нет; она работает и без плагина. Мастер предлагает preview и отдельную активацию
уже установленной темы; ZIP устанавливает владелец вручную.

Решения прежние: данные в плагине, независимые компоненты, IANA timezone/DST,
закрытая переписка, подтверждаемый мастер с сохранением ручных изменений.
