# Статус «Прихода»

Готовы этапы 1–3, версия 0.3.0: Core; полное расписание с исключениями/DST,
блоками, шорткодами и печатью; публичные обращения без регистрации и закрытый кабинет.
Обращения: статусы, ответственный, внутренние заметки, история ответов, фоновая
email-отправка с повторными попытками, отдельные capabilities, retention закрытых
обращений, WordPress privacy export/erase. Оба модуля отключаются без удаления данных.

Решения: личные обращения и сообщения — отдельные private CPT без публичного REST,
без обычных комментариев WordPress. Nonce, одноразовая форма, honeypot, consent,
лимит отправок и атомарные блокировки. SMTP-приём письма не означает доставки в inbox.
Ответ посетителю отправляется по email; автоматический приём входящих email ещё не реализован.
Полное ТЗ сохранено. Владелец устанавливает ZIP сам, production не изменяется.

Проверки: PHP 8.4 syntax, 56 unit assertions; WordPress 6.5.13 / PHP 8.4.25 / SQLite —
39 integration assertions, всё прошло. Проверены очередь/ошибки email (перехват транспорта
в тестовом WordPress), доступ, экспорт, удаление истории, лимит и блокировки.
Diff/check/stat проверены перед commit. Живая почта, MySQL/Plesk и браузерная QA не проверялись.

Далее: этап 4 мастер (анализ/интервью/план/подтверждение/черновики/повторный запуск),
этап 5 тема, этап 6 реальные интеграции. Вложения и кабинет посетителя — последующее развитие.
Cron WordPress должен работать для email и retention; cache-исключение для формы требуется
при использовании полного page cache (одноразовый токен действует час).
