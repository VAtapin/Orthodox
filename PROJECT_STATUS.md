# Статус «Прихода»

Реализованы этапы 1–6: Core, расписание, закрытые обращения, безопасный мастер,
права/диагностика/очистка и самостоятельные тема/подключения. Текущее состояние:
Core 1.0.0-rc.2, тема 0.2.1, Telegram/WhatsApp/Facebook подключения 0.1.1.
Сборка ZIP — python scripts/package.py. Это release candidate.

Тема соответствует композициям предоставленных макетов: пять схем, четыре
шаблона внутренних страниц, реальные данные Core, новости, медиатека и галерея.
Русский, немецкий, польский и украинский UI; материалы не переводятся автоматически.
Фотографии выбирает владелец. Сохранённые стили/шаблоны WordPress имеют приоритет.
Исходные 15 PNG сохранены побайтно в docs/design-reference/screenshots с manifest/SHA-256;
оригинальный docs/UI не изменён. Браузерные снимки сохранены отдельно.

Дашборд «Прихода»: сведения, ближайшие службы, статусы обращений, подключения и
заметная кнопка мастера. Меню разделено на дашборд, информацию, обращения, наши
плагины, настройки и мастер; формы доступны кнопками с прежними capabilities.
Четыре информационных виджета в консоли WordPress; приватные данные защищены правами.
Настройки подключений находятся внутри плагина; без Core подключения имеют собственные меню.

Мастер: приветствие и шесть групп поверх 14 подробных этапов; подтверждения
черновиков и публикации сохранены. Расписание имеет разные неделю, месяц-сетку и
список с навигацией по периодам. Исправлено сохранение кириллицы в навигации.
Тема оформляет настоящие формы, включая три шага пожертвования и пять шагов записки;
платёжная логика остаётся во внешнем плагине. Поддержан Orthodox Donations 1.0.2,
включая старые страницы со шорткодами kloster_*. Календарь 1.3.78 использует публичный API
без ключа. Данные и бизнес-логика находятся в Core и исходных плагинах.

По прямым разрешениям установлен WordPress 7.1.3 и компоненты на prihod.georg-kloster.ru.
Это отдельный WordPress на ОБЩЕМ БОЕВОМ сервере с другими живыми сайтами.
Дальнейшие действия — только внутри этого WordPress; не менять Plesk/окружение,
другие сайты и не добавлять блокировки. Добавленная ранее WordPress-блокировка снята;
HTTP/email не блокируются. Календарь получает реальные данные. Пароль админа изменён
владельцем; первоначальный установочный файл устарел. Credentials не включены в Git.
Окружение именно этого сайта: PHP 8.5.11, MariaDB 10.6.23. Команды — docs/TEST_SERVER.md.

Проверки: PHP syntax, 57 unit assertions, JavaScript syntax, 1284 проверенных
переводных UI-сообщения и placeholders. WordPress Playground/SQLite: 139 assertions

128 assertions на WP 6.5.13 / PHP 8.0.30. Самостоятельные тема/подключения проверены.
Браузерная QA: пять схем, четыре языка, мобильные виды, мастер, формы и дашборды.
