# Статус «Прихода»

Core 1.0.0-rc.6, тема 0.3.7, Telegram/WhatsApp/Facebook 0.1.1.
Реализованы этапы 1–6: Core, расписание, обращения, мастер, права/диагностика/
очистка и самостоятельные тема/подключения. Сборка: python scripts/package.py.
Это release candidate. ТЗ и 16 исходных изображений сохранены.

Тема: пять самостоятельных композиций главной, текстовые/широкие/каталожные/
сфокусированные страницы, история с временной шкалой, реальные связанные статьи.
Панель с семью разделами, фотографиями отдельных карточек и необязательной OSM-картой.
Предпросмотр владельца сохраняется при переходах, не меняет публичную схему.
Ручные правки демо, пользовательские шаблоны и стили сохраняются.
Русский, немецкий, польский, украинский UI; контент не переводится автоматически.

Core: «Обзор прихода», тематическое меню, общая верхняя навигация, четыре виджета
консоли. Расписание: компактные реальные строки, неделя/месяц/список, мини-месяц
с учётом места, раскрываемое описание, сохранённые даты ночных служб и статусы.
В списке служб видны дата/время/часовой пояс, место, тип/повторение и исключения;
дата публикации отделена, на телефоне дата службы видна без раскрытия строки.
Мастер показывает фактическую публикацию; доступные черновики перед свёрнутым
списком остальных ресурсов, подтверждение и защита ручных правок сохранены.

На prihod.georg-kloster.ru опубликованы 13 страниц, главная ID 7, тематическое меню,
шесть материалов и восемь фотографий с georg-kloster.ru, настоящее духовенство
и пять разовых октябрьских литургий. Набор монастыря — отдельный явный импорт,
не часть универсальных ZIP; docs/MONASTERY_DEMO.md. Сохранён выбранный владельцем
тип организации parish. Календарь/расписание/галерея без дублирующей боковой колонки.

Тема исправляет JSON календаря при обработке shortcode и заранее регистрирует
штатные assets формы пожертвования. Исходники orthocal 1.3.78 и Orthodox Donations
1.0.2 не изменялись. Реальные оплаты, письма и внешние публикации не выполнялись.
Внешние аккаунты и оплата требуют отдельной проверки владельцем.

Общий БОЕВОЙ сервер Plesk содержит другие живые сайты. Изменения ограничены данным
WordPress и wp-content. Plesk/окружение, другие сайты и credentials не менялись,
HTTP/email не блокируются. PHP сайта 8.5.11; команды — docs/TEST_SERVER.md.

Проверки: PHP syntax, 57 unit assertions, JavaScript syntax, 1707 переводных UI
сообщений/placeholder. Playground WP 7.1.3/PHP 8.4.25 — 196 assertions;
WP 6.5.13/PHP 8.0.30 — 185. Standalone-компоненты и импорт
13 страниц/6 материалов/8 медиа с повтором/ручной редактурой — пройдены;
52 проверки структуры по макетам. На живом WordPress — 44 проверки.
Браузер: 65 сочетаний страниц и схем, пять видов статьи, четыре мобильных страницы,
настоящие формы до последнего шага без отправки, итог мастера и панель темы.
Снимки и ограничения — docs/DESIGN_CONFORMITY.md. Переполнения и повреждённых
загруженных изображений в матрице не обнаружено. Удалённый CI не заявляется пройденным.
