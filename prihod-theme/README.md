# Тема «Приход» 0.3.1

Универсальная блоковая тема, WordPress 6.5+, PHP 8.0+. Работает самостоятельно,
бизнес-данные и операции остаются в Core и подключённых плагинах. Установка ZIP
и активация выполняются владельцем отдельно.

Пять схем в «Внешний вид → Редактор → Стили»: стандартная классическая золотая,
светлая гостеприимная, журнальная, традиционная и современная синяя.
Схемы меняют палитру, карточки, структуру главного экрана и подвал. Сохранённые
пользователем настройки/шаблоны WordPress имеют приоритет над файлами темы.

Шаблоны: обычная страница/запись с правой колонкой, wide (без колонки), catalog
(каталог материалов), focused (форма/подтверждение). На главной выводятся реальные
опубликованные страницы Core, ближайшие службы, новости, выбранные фото и контакты.
Дополнительные блоки содержимого главной редактируются стандартным редактором.
При отсутствии Core отображаются название/описание сайта и записи WordPress.
Без календаря его карточка не появляется; неактивные формы не подменяются имитацией.

«Приход → Настройки → Оформление прихода»: выбор фотографий из медиатеки, галерея,
ссылка на карту, адреса существующих языковых версий. Изображения макетов не
являются фотографиями вашего сайта. Без изображений предусмотрен нейтральный фон.
Внешние карты не загружаются автоматически: посетитель сам открывает ссылку.

Русский — язык исходных строк. В комплекте PO/MO немецкого de_DE, польского pl_PL
и украинского uk. Язык UI задаётся WordPress/языковым плагином; языковой профиль
Core не меняет WordPress самовольно. Есть переключатель существующих страниц
Polylang/WPML либо вручную заданных URL. Материалы, меню, название прихода и описание
не переводятся автоматически; версии контента создаёт владелец. Даты используют
языковой пакет WordPress; названия месяцев и дней расписания переводит Core.
Для полноценного меню нужны опубликованные страницы.

Оформление календаря orthocal и форм kloster-prayer использует их настоящие
CSS-переменные, не заменяет платёжную логику, поля, проверку согласия или статусы.
Состояния платежа всегда определяет исходный плагин. Скриншоты — ориентир композиции,
а не источник фиксированных сумм, праздников или персональных данных.
Для совместимого Orthodox Donations 1.0.2 (также поддерживается прежний kloster-prayer 1.2.15) тема предлагает пошаговое заполнение:
пожертвование — три шага, записки — пять. Поля и расчёты исходного плагина сохраняются;
оплата начинается только его штатной кнопкой на последнем шаге. Настройку можно
отключить в «Оформлении прихода»; без JavaScript остаётся штатная форма.

Сборка: python scripts/package.py. Переводы: python scripts/compile-translations.py.
Оригиналы и браузерные снимки проверки: docs/design-reference/ в репозитории.
GPL-2.0-or-later; полный текст включён в LICENSE.txt.

При активном Core настройки оформления находятся внутри плагина «Приход».
Самостоятельная тема сохраняет свою страницу во «Внешнем виде».

В версии 0.3.0 появилась панель с семью разделами: оформление (пять схем прямо
в панели), макет/шрифты, фотографии/логотип, шапка/подвал, формы, языки и демо.
Ширина 960–1440 px, основной текст 14–20 px, два системных шрифта; закрепление
шапки, показ контактов и дополнительный текст подвала. Настройки применяются
через штатный theme.json фильтр WordPress; собственные стили редактора сохраняют приоритет.
https://developer.wordpress.org/reference/hooks/wp_theme_json_data_theme/

«Демо-страницы» создаёт выбранные страницы с редактируемыми примерными текстами,
обычными блоками и настоящими формами установленных плагинов. Доступны главная,
о приходе, духовенство, первый визит, расписание, обращения, новости, проповеди,
контакты, галерея и страницы доступных календаря/записок/пожертвований.
При активном Core используется Site_Plan, его реестр ресурсов и права.
Отключённые модули не включаются автоматически. Самостоятельная тема создаёт
шесть обычных страниц. Активация не импортирует материалы самовольно.
По умолчанию — черновики; публикация, главная и навигация выбираются отдельно.
Повторный импорт сохраняет страницы, ручные правки и корзину. Редактированные
черновики не публикуются массово. Фотографии и реальные сведения добавляет владелец.

В 0.3.1 доступны пять предварительных видов главной для владельца без изменения
сохранённых стилей. Полный календарь исключает повтор в боковой колонке; календарь,
расписание и галерея получают широкий демо-шаблон. Тип «Монастырь» меняет приветствие
и подписи главной на подходящие обители. Редакционные демо-материалы монастыря
поставляются отдельно от универсальной темы (docs/MONASTERY_DEMO.md).
