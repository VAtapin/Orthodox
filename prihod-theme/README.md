# Тема «Приход» 0.1.0

Необязательная блоковая тема, WordPress 6.5+, PHP 8.0+. Без внешних шрифтов, зависимостей
и сбора данных. Информация и функции принадлежат плагину «Приход», а не теме.

Установка: ZIP с каталогом `prihod-theme` через «Внешний вид → Темы → Добавить тему».
После установки отдельно открыть предварительный просмотр и при желании активировать.
Установка и активация не выполняются автоматически плагином.

В редакторе сайта доступны header/footer, шаблоны главной, страниц, записей и списка.
Варианты: стандартный бумажный, светлый и вечерний. При активном «Приходе» доступны
patterns главной, недели служб и контактов. Навигацию мастера выбрать штатным редактором.
Без плагина тема продолжает отображать стандартные страницы и записи WordPress.
