# Мобильная читаемость hospitality

Проверить главную в hospitality при390×844 и430×900, затем desktop1122×1402.
Тексты и фотографии не менять ради проверки; не сохранять схему предпросмотра.

- Заголовок, описание и цитата полностью находятся внутри светлой подложки.
- Ни один текст не обрезан, нет горизонтального переполнения.
- Для тёмного текста на rgba(255,255,255,.96) считать нижнюю границу контраста
  поверх чёрного фото: итоговый канал255×.96. sRGB-линеаризация и относительная
  яркость0.2126R+0.7152G+0.0722B, контраст(Lmax+.05)/(Lmin+.05).
- По фактическим computed styles нормальный текст/цитата не ниже4.5:1,
  крупный заголовок не ниже3:1. Значения измерять после установки viewport.
- На desktop подложка не включается: первый экран, фото и правая служба сохраняются.
- Снимки обеих мобильных ширин и desktop сохранять с начала страницы.
