== Description ==

Этап Core системы «Приход»: профиль, несколько мест служения, духовенство,
отдельные capabilities и контракт расширений. Работает независимо от темы.

Расписание: регулярные/разовые/праздничные службы, исключения, переносы,
неделя/месяц, печать, ближайшая служба. Блоки и шорткоды основных сведений и расписания.
Обращения: гостевая форма, закрытый кабинет, статусы, ответственные, заметки,
история, очередь email, сроки хранения, privacy export/erase.
Мастер: анализ сайта, интервью, подтверждение плана, черновики, preview,
отдельная публикация, главная/меню по выбору и повторный запуск без дублей.
Диагностика, назначение прав и отдельная явно подтверждаемая очистка.
Адаптеры существующих календаря и «Записок», включая самостоятельные пожертвования.
Telegram, WhatsApp и Facebook доступны отдельными необязательными плагинами.

При активации плагин не меняет страницы, главную или меню. Мастер применяет
выбранный план только после подтверждения. Другие компоненты устанавливает владелец.

== Installation ==

1. Поместить каталог prihod в wp-content/plugins/ или загрузить ZIP.
2. Активировать плагин «Приход».
3. Заполнить сведения вручную или открыть «Приход → Мастер настройки».

== Frequently Asked Questions ==

= Удаляются ли данные при деактивации или удалении плагина? =

Нет. Данные и выданные capabilities сохраняются.

= Нужна ли специальная тема? =

Нет. Основные функции принадлежат плагину.
