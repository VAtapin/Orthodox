Сведения о православном приходе, местах служения и духовенстве.

== Description ==

Этап Core системы «Приход»: профиль, несколько мест служения, духовенство,
отдельные capabilities и контракт расширений. Работает независимо от темы.

Расписание, обращения, Gutenberg-блоки, мастер и реальные внешние интеграции
в этой версии ещё не реализованы.

Плагин не создаёт страницы, не изменяет главную или меню, не устанавливает
другие компоненты и не подключает внешние сервисы.

== Installation ==

1. Поместить каталог prihod в wp-content/plugins/ или загрузить ZIP.
2. Активировать плагин «Приход».
3. Заполнить «Приход → Сведения о приходе», добавить места и духовенство.

== Frequently Asked Questions ==

= Удаляются ли данные при деактивации или удалении плагина? =

Нет. Данные и выданные capabilities сохраняются.

= Нужна ли специальная тема? =

Нет. Основные функции принадлежат плагину.
